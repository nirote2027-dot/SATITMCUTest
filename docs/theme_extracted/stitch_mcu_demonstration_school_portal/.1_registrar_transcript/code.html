ตัดสินผลการเรียน: ผ่านเกณฑ์สำเร็จการศึกษา
ตามระเบียบกระทรวงศึกษาธิการ ปี พ.ศ. 2551
แบบรายงานผลการประเมินกิจกรรมและคุณลักษณะอันพึงประสงค์ (ด้านหลัง ปพ.1:พ) ผู้เรียน: นายปวริศ มหาจุฬารัตน์ (เลขประจำตัว 14285) • โรงเรียนสาธิตมหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย
1. การประเมินกิจกรรมพัฒนาผู้เรียน (Student Development Activities) สรุปผล: ผ่านครบทุกกิจกรรม
รายการกิจกรรม ม.4 (ภาค 1 / 2) ม.5 (ภาค 1 / 2) ม.6 (ภาค 1 / 2) สรุปผลตลอดหลักสูตร
1.1 กิจกรรมแนะแนว (Guidance) ผ / ผ ผ / ผ ผ / ผ ผ่าน (Pass)
1.2 กิจกรรมนักเรียน (ลูกเสือ/รด./ชุมนุมพุทธศาสน์) ผ / ผ ผ / ผ ผ / ผ ผ่าน (Pass)
1.3 กิจกรรมเพื่อสังคมและสาธารณประโยชน์ (MCU Volunteer) ผ / ผ ผ / ผ ผ / ผ ผ่าน (Pass)
* ผ หมายถึง ผ่านเกณฑ์การประเมินเวลาเรียนไม่น้อยกว่าร้อยละ 80 และผ่านจุดประสงค์สำคัญ
2. การอ่าน คิดวิเคราะห์ และเขียน ดีเยี่ยม (3)
  • • การอ่านเพื่อศึกษาค้นคว้าและเพิ่มพูนความรู้ ระดับ 3 (ดีเยี่ยม)
  • • การคิดวิเคราะห์ สังเคราะห์ และวินิจฉัย ระดับ 3 (ดีเยี่ยม)
  • • การเขียนสื่อความและสะท้อนทรรศนะเชิงสร้างสรรค์ ระดับ 3 (ดีเยี่ยม)
3. คุณลักษณะอันพึงประสงค์ ดีเยี่ยม (3)
1. รักชาติ ศาสน์ กษัตริย์: ดีเยี่ยม
2. ซื่อสัตย์สุจริต: ดีเยี่ยม
3. มีวินัย: ดีเยี่ยม
4. ใฝ่เรียนรู้: ดีเยี่ยม
5. อยู่อย่างพอเพียง: ดีเยี่ยม
6. มุ่งมั่นในการทำงาน: ดีเยี่ยม
7. รักความเป็นไทย: ดีเยี่ยม
8. มีจิตสาธารณะ: ดีเยี่ยม

1. ผู้เรียนเรียนรายวิชาพื้นฐานและเพิ่มเติม ครบ 81 หน่วยกิต โดยเป็นรายวิชาพื้นฐาน 41 หน่วยกิต และรายวิชาเพิ่มเติมตามเกณฑ์สถานศึกษากำหนด
2. ผู้เรียนต้องได้ผลการประเมินกิจกรรมพัฒนาผู้เรียน "ผ่าน" ทุกกิจกรรม
3. ผู้เรียนต้องได้ผลการประเมินการอ่าน คิดวิเคราะห์ และเขียน ในระดับ "ผ่าน" ขึ้นไป
4. ผู้เรียนต้องได้ผลการประเมินคุณลักษณะอันพึงประสงค์ ในระดับ "ผ่าน" ขึ้นไป
